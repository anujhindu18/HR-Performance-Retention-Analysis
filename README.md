# HR Performance & Retention Analysis

## Project Overview
An HR Analytics project using **SQL and Power BI** to analyze employee performance, attrition, and retention. The project aims to identify workforce trends and understand the factors influencing employee turnover.

## Tools & Technologies
- SQL Server (SSMS)
- Microsoft Power BI
- DAX

## Key Analysis
- Employee attrition and retention rates.
- Department-wise employee turnover.
- Employee demographics and job roles.
- Job satisfaction and performance analysis.
- Workforce trends and insights.

## Project Objective
To transform HR data into meaningful insights that help organizations improve employee retention, monitor workforce performance, and make data-driven HR decisions.
