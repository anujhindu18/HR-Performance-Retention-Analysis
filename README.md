# HR Performance & Retention Analysis

## Project Overview
An HR Analytics project using **SQL Server and Power BI** to analyze employee performance, attrition, and retention. The project aims to identify workforce trends and understand the key factors influencing employee turnover.

## Dataset
- Downloaded the HR Analytics dataset from Kaggle.
- Dataset contains employee-related information used to analyze attrition, job satisfaction, demographics, performance, and retention.
- The dataset will be used for SQL analysis and Power BI dashboard development.

## Tools & Technologies
- SQL Server (SSMS)
- Microsoft Power BI
- DAX
- Kaggle (Dataset Source)

## Key Analysis
- Employee attrition and retention rates.
- Department-wise employee turnover.
- Employee demographics and job roles.
- Job satisfaction and performance analysis.
- Workforce trends and insights.
- Factors influencing employee attrition.

## Project Objective
To transform HR data into meaningful insights that help organizations improve employee retention, monitor workforce performance, understand employee turnover, and make data-driven HR decisions.

## Project Workflow
1. Download HR Analytics dataset from Kaggle.
2. Explore and understand the dataset.
3. Perform data cleaning and analysis using SQL Server.
4. Create analytical measures using DAX.
5. Develop interactive dashboards in Power BI.
6. Generate insights into employee performance and retention.

## Expected Outcomes
- Better understanding of employee attrition.
- Identification of departments with higher turnover.
- Insights into employee satisfaction and performance.
- Data-driven recommendations for improving employee retention.
